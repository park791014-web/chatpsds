## 🛠️ Streamlit Cloud 배포 및 UI 오버레이 설정 안내

본 프로젝트는 배포 시 깔끔하고 통일된 다크 테마 브랜딩을 제공하기 위해 Streamlit의 기본 상하단 툴바 및 오버레이 장치들을 정밀 제어하고 있습니다.

### 1. 상하단 툴바 및 장식 요소 정밀 제거
- 상단 툴바 및 배포 관련 단추(Share, Star, Edit, GitHub, ⋮ 메뉴)와 푸터 배지("Made with Streamlit")를 CSS로 정교하게 지우는 `hide_streamlit_chrome()` 함수가 `utils/ui.py`에 구축되어 메인 화면 로딩 시 즉각 실행됩니다.
- 이 과정에서 사이드바 접기/열기 단추(»/«)가 있는 **Header 레이어는 절대로 감추거나 높이를 0으로 만들지 않고 투명화 및 높이만 슬림하게 튜닝(2.75rem)**하여 사이드바 토글이 무조건 정상적으로 드러나고 클릭 가능하도록 설계했습니다.

### 2. 라이브 배포 시 "Manage app" 버튼 안내
- **안내 사항**: 우상단/우하단에 나타나는 Streamlit Community Cloud의 **"Manage App"** 대시보드 단추는 Streamlit Cloud 관리용 호스트(Host) 레이어에서 주입하는 아이프레임(iframe) 외부 요소입니다.
- **가시성 범위**: 이 버튼은 해당 Streamlit Cloud 계정에 로그인한 **프로젝트 소유자(개발자 본인)에게만 노출**되며, 링크를 통해 접속하는 **일반 사용자(동료 교사, 학생 등) 화면에는 전혀 표시되지 않습니다.**
- **대응 방향**: 브라우저 보안 정책상 아이프레임 내부 앱 코드(CSS/JS)로 외부 호스트의 버튼을 인위적으로 숨기는 취약한 크로스도메인 해킹은 배제하였습니다. 일반 배포 접속 환경에서는 완벽하게 보이지 않는 상태이므로 안심하셔도 됩니다.

### 3. Streamlit 버전 고정
- Streamlit의 잦은 업데이트로 내부 DOM 구조(data-testid 등)가 무단 변경되는 것을 막기 위해, `requirements.txt`에 현재 개발 및 검증을 완료한 버전인 **`streamlit==1.61.1`**로 정확히 버전 락(Lock)을 걸어두었습니다.
